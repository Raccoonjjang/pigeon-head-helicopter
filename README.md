# 発音矯正アプリケーション (Android)

## 📌 プロジェクト概要
本アプリケーションは **後天的な聴覚障害者** のための発音学習支援アプリです。  
画面に表示された単語を利用者が発音すると、**韓国電子通信研究院（ETRI）の発音評価API** を用いて正確度を解析し、スコアを提示します。  
これを繰り返すことで発音を矯正し、学習効果を高めることを目的としています。  

---

## 🔑 主な機能
1. **単語学習モード**  
   - 画面に単語を順次表示  
   - 利用者が単語を見て発音を試みる  

2. **発音評価（ETRI API 利用）**  
   - 利用者の音声を録音し、ETRI 発音評価APIに送信  
   - APIのレスポンスにより発音の正確度（0〜100点）を算出  

3. **フィードバック提供**  
   - 正しい発音の場合：ポジティブなフィードバックを表示し、次の単語へ進行  
   - 発音が不十分な場合：再発音を促し、改善ポイントを提示  

4. **反復トレーニング**  
   - 単語リストに基づく繰り返し学習  
   - スコア履歴の記録および学習成果の確認が可能  

---

## ⚙️ 技術スタック
- **開発環境:** Android Studio (Java / Kotlin)  
- **音声処理:** 韓国電子通信研究院（ETRI）発音評価API  
- **UI:** Android XML レイアウト  
- **データ管理:** ローカルDB（SQLite）またはクラウド連携  

---

## 🚀 利用フロー
1. アプリ起動後、学習する単語を選択  
2. 単語が画面に表示される  
3. 利用者が発音 → マイク入力を収集  
4. 録音音声を **ETRI発音評価API** に送信  
5. APIから発音スコアを受信し、画面にフィードバックを表示  
6. 繰り返し学習を通じて発音を改善  

---

## 📈 期待される効果
- 後天的聴覚障害者の発音訓練を支援  
- 単語の反復学習による **発音矯正と自信向上**  
- APIに基づく定量的フィードバックにより自己主導的な学習が可能
